# MuJoCo Terrain Editor

[English](README.md) | [简体中文](README-zh.md)

纯前端 MuJoCo 地形编辑器。通过 Web 3D 界面组合方块、圆柱、斜坡、楼梯和平台，并导出可直接加载的 MJCF XML。

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 使用方法

1. 从左侧组件库拖拽地形到视口；双击组件可添加到原点。
2. 点击地形后，使用顶部工具移动或旋转；右侧面板可精确编辑尺寸和变换。顶部可切换中英文和浅色/深色主题，默认中文浅色界面。
   视口在浅色和深色主题下均使用柔和光照。
3. 默认启用“自动贴地”，地形底面会保持在 `Z = 0`；取消勾选后可自由编辑高度。
4. 编辑 `Geom 名称`，该名称会直接用于导出的 MJCF `<geom name="...">`。
5. 点击“导出 XML”会下载带时间戳的文件，例如 `terrain_08_06-21_21_.xml`；之后可通过顶部“加载 XML”，或将 XML 文件拖入编辑器任意位置，恢复场景并继续编辑。导入文件后顶部会显示“保存”按钮，可在浏览器授予写入权限后直接覆盖原文件；载入新文件前会保护尚未导出或保存的修改。直接覆盖需要 Edge/Chrome 等支持本地文件访问 API 的浏览器。

视口操作：左键旋转相机或拖拽变换手柄，右键平移，中键或滚轮缩放。

复制可使用右侧“复制元素”按钮或顶部复制按钮；快捷键为 `Ctrl+D`（macOS 为 `Cmd+D`）。

撤回与反撤回：`Ctrl/Cmd+Z` 撤回，`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 反撤回。

其他快捷键：`W` 移动、`E` 旋转、`Shift/Ctrl/Cmd + 点击` 增选或取消选择、`Shift+[` / `Shift+]` 绕 Z 轴左转/右转 90°、`Delete` 删除、`Esc` 取消选择。多选物体可通过公共移动手柄整体移动。

## 编辑约定

- 场景、变换手柄和右下角坐标指示器统一使用 Z-up 右手坐标系，长度单位为米，角度单位为度。
- 变换步长：移动 0.05 m、旋转 1°。
- 移动手柄使用世界坐标；旋转手柄使用元素局部坐标。多选状态当前仅支持整体移动。
- 名称仅使用 ASCII 字母、数字、下划线、连字符和点，以保证 MJCF 兼容性。

## 地形参数

- 方块：宽度、长度、高度。
- 圆柱：半径、高度。
- 斜坡：坡面宽度、水平长度、坡度。
- 楼梯：踏步宽度、踏步长度、踏步高度、级数；默认沿 X 轴正方向逐级升高。开启“悬浮楼梯”后，各级变为独立踏步，并显示厚度选项（默认 `0.05 m`）。自动贴地使最低一级踏步的底面保持在 `Z = 0`。
- 平台：平台宽度、长度、高度。

默认尺寸和新地形类型统一定义在 [`src/data/presets.js`](src/data/presets.js)。修改参数的 `default` 即可更新默认尺寸；新增地形时添加一个 `defineTerrainPreset` 配置，组件库、属性面板、自动贴地和 XML 导出会自动接入。

编辑器级吸附步长和手柄尺寸集中定义在 [`src/editorConfig.js`](src/editorConfig.js)。

### 随机方块

选中方块，在几何参数中勾选“生成随机方块”，即可设置数量（`1–200`），以及长、宽、高和 Yaw 的最小值与最大值。尺寸单位为米，Yaw 为绕局部 Z 轴的角度（`−180° 至 180°`，默认 `0°`）。方块中心可落在整个底座范围内，旋转后超出边缘和角落的部分会被裁掉。小方块可能重叠。点击“重新生成”可换一组布局，也可输入“方块随机种子”来复现布局。

小方块跟随底座移动和旋转。同时启用“应用 Perlin 噪声”时，每个小方块按其中心下方的基面高度放置，顶面与底座采样同一噪声场，旋转和裁切后的顶面同样有起伏。导出的 MJCF 包含粗糙表面的碰撞网格，重新导入编辑器时会恢复生成参数。

点击“导出高度图”会下载 ZIP，包含 `terrain.xml` 和每个启用随机方块或 Perlin 噪声的 Box 对应的一张灰度 PNG。将文件解压到同一目录，再用 MuJoCo 打开 `terrain.xml`。高度图在最长边上划分 256 个间隔，采样每处的最高表面并保存为 256 级高度。竖直台阶和裁切边会按网格近似。需要原始碰撞几何时，使用“导出 XML”。其他地形元素沿用常规导出格式。

### Perlin 表面粗糙度

所有地形类型均提供“应用 Perlin 噪声”复选框，启用后显示：

- 噪声高度：正负起伏范围，单位为米，默认 `±0.02`。
- 噪声高度步长：高度场的量化步长，单位为米，默认 `0.01`。插值前将高度量化到该步长，范围上限也按最近步长取整。
- 噪声频率：单位为 `1/m`，默认 `2`；数值越大，起伏越细密。
- 随机种子：用于复现相同表面的整数，默认 `1`。
- 表面细分数：沿整个地形最长边的细分数，默认 `16`，范围 `4–32`；提高细分数可呈现更细的噪声。

粗糙度采用 LocoLab 的共享采样逻辑：两个梯度 Perlin 噪声层，权重为 `1` 和 `0.25`，依次进行均值居中、正负范围缩放、高度量化及双线性采样。种子也会在一个倍频程内调整基础波长；频率受网格间距限制，以避免欠采样。

带噪声的上表面使用哑光着色、清晰的边界和轻微的高度明暗变化，便于观察细小起伏，不改变几何形状和导出颜色。使用顶部“粗糙度线框”按钮可显示低对比度的检查网格，默认隐藏。

所有踏步采样同一个覆盖整个地形的噪声场。仅地形最外侧保留一个网格宽的平坦边界，内部踏步边缘随噪声起伏。噪声作用于局部上表面（包括圆柱顶面），平面轮廓及底面保持不变；对薄踏步限制过深的凹陷，至少保留 `1 mm` 厚度。支持撤回、反撤回及 XML 导入导出。导出时合并仍能构成凸体的相邻碰撞分块。网格内嵌在 MJCF 中，并保留表面起伏。细分数越高，XML 文件越大，仿真开销也越高。
